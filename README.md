# 麻雀大会 スコア計算アプリ

麻雀大会（マイマイカップ形式・全4回戦）用の、ブラウザだけで動くスコア計算アプリです。
**馬（ウマ）計算**・**卓組みの自動割り振り**・**総合順位のリアルタイム反映**に対応しています。

インストール不要・サーバー不要。`index.html` を開くだけで使えます。

---

## 主な機能

### 1. ポイント計算（馬・オカ）

1卓ぶんの点数を入れると、着順とポイントが即座に計算されます。

```
ポイント = 素点pt ＋ ウマ
素点pt  = (最終点 − 30,000) ÷ 1000
```

| 設定項目 | 初期値 |
| --- | --- |
| ウマ（順位点） | **1位 +20 / 2位 +10 / 3位 −10 / 4位 −20** |
| 配給原点 | 25,000点スタート |
| 返し点 | 30,000点バック |
| オカ | **なし** |
| 端数処理 | 四捨五入 |

素点の換算例:

| 最終点 | 素点pt |
| --- | --- |
| 33,000点 | **+3** |
| 30,000点 | ±0 |
| 25,000点（スタート地点のまま） | **−5** |
| 17,000点 | −13 |

つまり 33,000点でトップなら `+3 ＋ 20 = +23pt` になります。

- **同点のときは席順（東 → 南 → 西 → 北）が上位**になります。
- オカなしのため、**1卓あたりの合計は −20** になります（4人ぶんを足しても0にはなりません）。オカを使いたい場合は設定で「オカあり」をオンにすると、1位に +20pt が入り合計が ±0 になります。
- 端数処理で生じた丸め誤差は1位が吸収して、卓の合計が理論値どおりになるようそろえます（設定でオフにできます）。1位に余分なポイントが入ることはありません。
- 「素点をポイントに加算する」をオフにすると、**順位点のみ（+20 / +10 / −10 / −20）**のシンプルな計算に切り替わります。
- 設定画面に計算例のプレビューがあるので、ルール変更の結果をその場で確認できます。

### 2. 卓組みの自動割り振り

大会規定どおりの組み合わせを、ボタンひとつで生成します。

| 回戦 | 割り振り方式 |
| --- | --- |
| 1回戦 | **ランダム抽選** |
| 2回戦 | **順位卓** — 1回戦の着順ごと（1位同士・2位同士…）に卓を組む |
| 3回戦以降 | **総合順位順** — その時点の総合順位で 1〜4位 / 5〜8位 / 9〜12位 … に卓分け |

- 各回戦のデフォルト方式は自動で選ばれますが、プルダウンで変更もできます。
- 名前をタップ → もう一人をタップで、**席を手動で入れ替え**られます（抜け番の人とも入れ替え可）。
- 参加人数が4の倍数でない場合は、**抜け番**が自動で決まります（抜け番の回数が少ない人から優先）。抜け番の回戦はポイント加算なしです。

### 3. 総合順位のリアルタイム反映

点数を入力したそばから、総合順位表が更新されます。

- 合計pt / 各回戦のpt・着順 / 素点合計 / 平均着順 / 着順分布（1着-2着-3着-4着）
- 同点の場合は **素点合計 → 1位回数 → 平均着順** の順で上位を判定
- チップ枚数と精算金額（初期値 300円/枚）
- 賞金表（初期値 1位30,000円 / 2位18,000円 / 3位10,000円 / 4位7,000円 / 5位5,000円）
- CSV書き出しに対応

### 4. その他

- 入力内容は**ブラウザに自動保存**されるので、画面を閉じても消えません
- JSONでバックアップの書き出し／読み込みが可能
- 「残り1人を自動計算」ボタンで、3人ぶん入力すれば4人目の点数を自動算出
- 点数の合計が 100,000点（25,000点 × 4人）と合わない場合は警告表示
- スマホ表示に最適化。ダークモード対応

## 使い方

1. `index.html` をブラウザで開く（スマホならホーム画面に追加しておくと便利です）
2. **プレイヤー**タブで参加者を登録（「まとめて追加」に改行区切りで貼り付けると一括登録できます）
3. **対局**タブで「卓組みを作成」→ 各卓の点数を入力
4. **総合順位**タブでリアルタイムの順位を確認
5. 次の回戦のタブに切り替えて「卓組みを作成」を繰り返す

ルール（ウマ・オカ・回戦数・チップ単価・賞金）はすべて**設定**タブから変更できます。

### ローカルで動かす

ファイルを直接開くだけで動きますが、簡易サーバー経由でも使えます。

```bash
npx serve .
# または
python3 -m http.server 8000
```

## Cloudflare Workers でのデプロイ

`wrangler.jsonc` を同梱しているので、**ビルド設定なしでそのままデプロイできます**。
Worker スクリプトを持たない「静的アセットのみ」の Worker として公開されます。

```jsonc
// wrangler.jsonc
{
  "name": "doyu-cup",
  "compatibility_date": "2026-09-12",
  "assets": { "directory": "./" }
}
```

### 公開されるファイル

公開対象は `.assetsignore` で絞り込んでいて、実際に配信されるのは次の3つだけです。

```
index.html / styles.css / app.js
```

`README.md`・`.github/`・`wrangler.jsonc`・`node_modules/` などは除外されます。
**ルート直下に置いたファイルは既定で公開対象になる**ので、大会データのバックアップJSONなど
公開したくないファイルをリポジトリに置く場合は、忘れずに `.assetsignore` へ追記してください。

### ダッシュボードから Git 連携で公開する

1. [Cloudflare ダッシュボード](https://dash.cloudflare.com/) → **Workers & Pages**
2. Worker `doyu-cup` → **Settings** → **Build** → リポジトリ `OfficePlata/doyu-cup` を接続
3. ビルド設定

   | 項目 | 値 |
   | --- | --- |
   | ビルドコマンド | **空欄のまま** |
   | デプロイコマンド | `npx wrangler deploy`（既定のまま） |
   | ブランチ | `claude/mahjong-scoring-app-qqrx5r` |

以降はプッシュのたびに自動デプロイされ、`https://doyu-cup.<サブドメイン>.workers.dev` で公開されます。

### 手元から手動でデプロイする

```bash
npx wrangler login
npx wrangler deploy
```

### GitHub Actions から（任意）

`.github/workflows/deploy-cloudflare.yml` を用意していますが、上記の Git 連携を使うなら不要です。
二重デプロイを避けるため**手動実行専用**にしてあります。使う場合はリポジトリの
**Settings → Secrets and variables → Actions** に `CLOUDFLARE_API_TOKEN` と
`CLOUDFLARE_ACCOUNT_ID` を登録し、Actions タブから Run workflow を実行してください。

## 構成

```
index.html       画面の骨組み
styles.css       スタイル（モバイル優先・ダークモード対応）
app.js           計算エンジン・卓組みロジック・描画（依存ライブラリなし）
wrangler.jsonc   Cloudflare Workers の配信設定
.assetsignore    公開対象から除外するファイル
```

外部ライブラリやビルド工程はありません。オフラインでも動作します。
